# http fun
Demo project to show that http keywords are convention not code.

## installation

You need [NodeJS](https://nodejs.org/en) (or similar) installed

```shell
git clone https://github.com/Stwissel/httpfun.git
cd httpfun
npm install
```

## running

```shell
node server.js
```

open your browser at [http://localhost:3000] and use the develope tools to watch the network.
